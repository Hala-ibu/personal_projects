# Personal Projects

A collection of small projects and programming exercises built while learning JavaScript and Java. Each folder is a separate experiment, so the repository is best explored project by project.

## Featured exercises

- **Color flipper** (`js/color_flipper/`) — change a page background to a chosen or randomly generated color, then restore its image background.
- **Palindrome checker** (`js/palidorum/`) — compare entered text with its reverse, ignoring letter case.
- **Java practice** (`java/`) — Maven-based examples exploring classes and objects, including student and mouse examples.

## Repository map

- `js/color_flipper/` — HTML, JavaScript, and image assets for the color exercise.
- `js/palidorum/` — HTML and JavaScript for the palindrome checker.
- `js/` — additional JavaScript practice files and notes.
- `java/pom.xml` — Maven project configuration.
- `java/src/main/java/org/example/` — Java source examples.

## Run the examples

For the browser exercises, open the relevant `main.html` file in a browser. To build the Java exercises, install a JDK compatible with the Maven compiler configuration and run Maven from the `java/` directory:

```bash
mvn package
```

These are focused learning exercises rather than one combined application.
